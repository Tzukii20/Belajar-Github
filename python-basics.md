# Python Basics

## What is Python?
Python is a programming language used for automation, data analysis, and artificial intelligence.

## Variables
Variables store data values.

Example:
name = "Estin"
age = 25

## Data Types
- String: text, such as "Hello"
- Integer: whole numbers, such as 10
- Float: decimal numbers, such as 3.14
- Boolean: True or false
